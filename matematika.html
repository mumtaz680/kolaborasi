Kolaborasi Matematika

Sistem Persamaan Linear Dua Variabel (SPLDV)

Tentang Kolaborasi Ini

Dalam mata pelajaran Matematika, kami mengaplikasikan konsep Sistem Persamaan Linear Dua Variabel (SPLDV) dalam konteks proyek daur ulang limbah. Melalui iklan yang telah kami buat, kami menunjukkan bagaimana matematika dapat digunakan untuk menentukan harga satuan dari iklan yang kami buat.

Iklan Yang Kami Kerjakan

Robot & Tas Bulat - Metode Campuran

Permisalan:
x = harga satuan Robot
y = harga satuan Tas Bulat

Permodelan:
2x + y = 165.000
x + 2y = 195.000

• Metode Eliminasi:
2x + y = 165.000    |x2
x + 2y = 195.000    |x1
________________
4x + 2y = 330.000
x + 2y = 195.000
________________   _
3x = 135.000
x = 45.000

• Metode Substitusi:
x + 2y = 195.000
45.000 + 2y = 195.000
2y = 150.000
y = 75.000

Kesimpulan: HP = {(45.000, 75.000)}. Jadi, harga 1 Robot = Rp 45.000 dan harga 1 Tas Bulat = Rp 75.000. Terbukti: 2(45.000) + 75.000 = 165.000.

Hiasan Dinding & Tas Bulat - Metode Campuran

Permisalan:
x = harga satuan Hiasan Dinding
y = harga satuan Tas Bulat

Permodelan:
3x + y = 210.000
x + 2y = 195.000

• Metode Eliminasi:
3x + y = 210.000    |x2
x + 2y = 195.000    |x1
________________
6x + 2y = 420.000
x + 2y = 195.000
________________   _
5x = 225.000
x = 45.000

• Metode Substitusi:
x + 2y = 195.000
45.000 + 2y = 195.000
2y = 150.000
y = 75.000

Kesimpulan: HP = {(45.000, 75.000)}. Jadi, harga 1 Hiasan Dinding = Rp 45.000 dan harga 1 Tas Bulat = Rp 75.000. Terbukti: 3(45.000) + 75.000 = 210.000.

Jam & Robot Daur Ulang - Metode Campuran

Permisalan:
x = harga satuan Click Clock Jam Dinding
y = harga satuan Robot Lampu Hias

Permodelan:
2x + y = 145.000
x + y = 95.000

• Metode Eliminasi:
2x + y = 145.000
x + y = 95.000
________________   _
x = 145.000 - 95.000
x = 50.000

• Metode Substitusi:
x + y = 95.000
50.000 + y = 95.000
y = 45.000

Kesimpulan: HP = {(50.000, 45.000)}. Jadi, harga 1 Jam Dinding = Rp 50.000 dan harga 1 Robot = Rp 45.000. Terbukti: 50.000 + 45.000 = 95.000.
